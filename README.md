# ⏱️ TimeTracker

Современное веб-приложение (Offline-First PWA) для удобного и точного отслеживания рабочего времени по задачам в течение дня.

> 📖 **История правок и детальный журнал изменений:** см. [CHANGELOG.md](CHANGELOG.md).

---

## ✨ Ключевые возможности

- 🚀 **Быстрый старт и дедупликация**: Введите название задачи — карточка мгновенно создается и запускается таймер. Если задача с таким именем уже существует за текущий день, таймер открывает новый рабочий интервал в существующей задаче, не создавая дубликатов.
- ⏸️ **Управление таймером**: Кнопки старта/паузы для каждой задачи с правилом одного активного таймера (при запуске новой задачи предыдущая автоматически ставится на паузу).
- 📡 **Offline-First & Синхронизация данных**:
  - Приложение полностью работоспособно при отсутствии интернет-соединения.
  - Локальный таймер продолжает отсчет времени без сбоев прямо в браузере.
  - Мгновенный отклик интерфейса (**Optimistic UI**).
  - Очередь отложенных сетевых действий (`Sync Queue`) сохраняется в `localStorage` и автоматически отправляется на сервер при восстановлении соединения.
  - Индикатор состояния сети (`Онлайн` / `Офлайн` / `Синхронизация`) с отображением количества элементов в очереди.
- 📱 **Progressive Web App (PWA) & Мобильный режим**:
  - Устанавливается как нативное приложение на смартфон (iOS, Android) или рабочий стол (macOS, Windows, Linux).
  - Автономный режим экрана (**Standalone mode**) без лишних панелей браузера.
  - Адаптация под вырезы экранов и челки (`safe-area-inset-*`).
  - Service Worker для кэширования статических файлов приложения.
- 🏷️ **Категории задач**:
  - Цветовая дифференциация по категориям: `work` (Работа), `study` (Учеба), `personal` (Личное), `other` (Другое).
  - Быстрое назначение и смена категории через выпадающий список `CategoryDropdown`.
- ⏱️ **Интерактивный таймлайн дня (`TimelineStrip`)**:
  - Горизонтальная 24-часовая шкала активности с визуализацией выполненных интервалов и активного таймера.
  - Цветовые отрезки по категориям с интерактивными подсказками (время, длительность, название задачи).
- 🕒 **Детализация периодов**: Внутри каждой карточки отображается список периодов работы (`с ЧЧ:ММ по ЧЧ:ММ (длительность)`), с возможностью ручного добавления, редактирования и удаления интервалов через удобные модальные окна.
- 🗑️ **Групповые операции**: Режим выбора задач чекбоксами и массовое удаление в один клик.
- ♿ **Доступность (a11y) и WAI-ARIA**:
  - Полная поддержка навигации с клавиатуры (`Tab`, `Shift+Tab`, `Enter`, `Escape`, стрелки).
  - Фокусные ловушки внутри модальных окон, предотвращающие потерю фокуса.
  - Семантические ARIA-роли и атрибуты (`role="dialog"`, `role="listbox"`, `aria-label`).
- 📅 **Интерактивный календарь и история**: Переключение дней (Сегодня, Вчера, стрелки вперед/назад, календарь за месяц с подсветкой дней с записями).
- 📊 **Аналитика дня**: Наглядная диаграмма распределения времени по задачам и категориям, общий таймер за день и динамическое отображение времени в заголовке вкладки браузера.
- 🌓 **Темная и светлая тема**: Автоматическое переключение (System) или ручной выбор Dark / Light.
- 📥 **Экспорт данных**: Возможность выгрузки истории за день или диапазон дат в формате CSV (с разбивкой по категориям и интервалам).
- 🐳 **Развертывание в Docker**: Всё приложение (бэкенд FastAPI + фронтенд на React + база SQLite) собирается в единый легковесный Docker-контейнер.

## 🚀 Развертывание на сервере (Тип 2: Сборка из исходников)

В соответствии со структурой сервера (категория пользовательских приложений `applications`):

1. Скопируйте проект в каталог на сервере:
   ```bash
   mkdir -p ~/services/applications/time-tracker/data
   cd ~/services/applications/time-tracker
   ```

2. Создайте файл окружения `.env` (при необходимости скорректируйте порт):
   ```bash
   cp .env.example .env
   chmod 600 .env
   ```

3. Запустите сборку и контейнер:
   ```bash
   docker compose build
   docker compose up -d
   docker compose logs -f
   ```

4. **Резервное копирование (`backup.sh`)**:
   - Каталог `~/services/applications/time-tracker/` автоматически подхватывается ежедневным бэкапом `~/scripts/backup.sh`.
   - Так как используется SQLite, для надежности добавьте `time-tracker` в массив `STOP_START_SERVICES` в файле `~/scripts/backup.sh` (для корректной консистентной остановки/запуска контейнера во время снятия бэкапа).

## 🛠️ Локальный запуск для разработки

Для быстрого запуска обоих серверов одной командой можно воспользоваться скриптом:
```bash
./run_local.sh
```

Или запустить раздельно:

### 1. Бэкенд (Python / FastAPI)

```bash
# Создание виртуального окружения
python3 -m venv .venv
source .venv/bin/activate

# Установка зависимостей
pip install -r backend/requirements.txt

# Запуск тестов
pytest backend/tests/

# Запуск сервера разработки
cd backend
uvicorn app.main:app --reload --port 8000
```

### 2. Фронтенд (React / Vite)

В отдельном окне терминала:

```bash
cd frontend
npm install
npm run dev
```

Фронтенд будет доступен по адресу **[http://localhost:3000](http://localhost:3000)** (все запросы к `/api` автоматически проксируются на бэкенд `http://localhost:8000`).

## 📡 Спецификация REST API

| Метод | Путь | Описание | Параметры / Тело запроса |
|---|---|---|---|
| `GET` | `/api/health` | Проверка здоровья сервиса | — |
| `GET` | `/api/tasks?date=YYYY-MM-DD` | Получить список задач и интервалов за выбранную дату | `date` (query, по умолчанию сегодня) |
| `POST` | `/api/tasks` | Создать задачу / открыть интервал в существующей | `{"title": "...", "date": "...", "category": "work", "auto_start": true, "id": "...", "at": "..."}` |
| `GET` | `/api/tasks/{task_id}` | Получить задачу по ID с её интервалами | — |
| `PATCH` | `/api/tasks/{task_id}` | Обновить параметры задачи | `{"title": "...", "category": "...", "date": "...", "order_index": 0}` |
| `DELETE` | `/api/tasks/{task_id}` | Удалить задачу и все её интервалы | — |
| `POST` | `/api/tasks/bulk-delete` | Массовое удаление задач | `{"task_ids": ["uuid-1", "uuid-2"]}` |
| `POST` | `/api/tasks/{task_id}/start` | Запустить/возобновить таймер задачи | `{"at": "ISO-TIMESTAMP", "interval_id": "uuid"}` (опционально) |
| `POST` | `/api/tasks/{task_id}/pause` | Поставить задачу на паузу | `{"at": "ISO-TIMESTAMP"}` (опционально) |
| `POST` | `/api/tasks/{task_id}/intervals` | Вручную добавить интервал времени к задаче | `{"start_time": "...", "end_time": "...", "id": "..."}` |
| `PUT` | `/api/intervals/{interval_id}` | Отредактировать время интервала | `{"start_time": "...", "end_time": "..."}` |
| `DELETE` | `/api/intervals/{interval_id}` | Удалить интервал времени | — |
| `GET` | `/api/days` | Список дат со статистикой для календаря | — |
| `GET` | `/api/days/{date}/summary` | Сводка и список задач за день | — |
| `GET` | `/api/export/csv` | Экспорт истории в формате CSV | `date_from`, `date_to` (query) |
